# Pawtion — เวอร์ชันแรก

เว็บคำนวณปริมาณอาหารรายวันสำหรับสุนัขและแมวแบบไม่ผูกกับแบรนด์ เปิด `index.html` ในเบราว์เซอร์เพื่อใช้งาน

## หลักการคำนวณ

ใช้ Resting Energy Requirement (RER) = `70 × น้ำหนักตัว(กก.)^0.75` และปรับด้วยปัจจัยของชนิดสัตว์ การทำหมัน ช่วงวัย ระดับกิจกรรม และสภาพร่างกาย เพื่อให้เป็น “ค่าเริ่มต้น” ของความต้องการพลังงานต่อวัน จากนั้นแปลงเป็นกรัมโดยอาศัยค่า `kcal/100g` ของอาหารจากฉลาก

อ้างอิงแนวคิด RER และค่าเริ่มต้นสำหรับสัตว์เลี้ยงสุขภาพดีจาก Merck Veterinary Manual และ WSAVA Global Nutrition Guidelines. เครื่องมือนี้ไม่ใช่คำแนะนำสำหรับสัตว์ป่วย ตั้งท้อง หรือให้นม
